# 핫딜뱅크 - 핫딜 & 알바 정보 커뮤니티

디스콰이엇 스타일의 온라인/오프라인 핫딜 정보와 알바 정보를 공유하는 커뮤니티 플랫폼입니다.

## 🎨 주요 기능

- **핫딜 정보 공유**: 온라인/오프라인 할인 정보 실시간 공유
- **알바 정보**: 단기/장기 아르바이트 정보 게시
- **커뮤니티**: 회원들 간의 정보 공유 및 소통
- **실시간 트렌딩**: 인기 핫딜과 알바 정보 확인
- **맞춤 알림**: 관심 카테고리별 알림 설정

## 🛠 기술 스택

- **Frontend**: React 18
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Routing**: React Router DOM
- **Build Tool**: Vite

## 📦 설치 및 실행

### 1. 의존성 설치

```bash
npm install
```

### 2. 개발 서버 실행

```bash
npm run dev
```

개발 서버가 `http://localhost:5173`에서 실행됩니다.

### 3. 프로덕션 빌드

```bash
npm run build
```

### 4. 빌드 미리보기

```bash
npm run preview
```

## 🎯 페이지 구성

### 1. 랜딩 페이지 (`/`)
- 서비스 소개
- 주요 기능 안내
- 카테고리 소개
- CTA 섹션

### 2. 로그인 페이지 (`/login`)
- 소셜 로그인 (구글, 링크드인)
- 이메일 로그인
- 커뮤니티 가이드

### 3. 피드 페이지 (`/feed`)
- 핫딜/알바 게시물 피드
- 카테고리 필터
- 트렌딩 토픽
- 인기 게시물

## 🎨 디자인 특징

- **컬러 시스템**: 오렌지-레드 그라데이션 (핫딜의 긴박함과 기회 표현)
